# Cluster: fu_underspec

### ji2026coding: Coding Agents Are Guessing: Measuring Action-Boundary Violations in Underspecified DevOps Instructions
Source checked: https://arxiv.org/abs/2607.02294, https://arxiv.org/bibtex/2607.02294, https://arxiv.org/pdf/2607.02294 (full v1 body, 9 pages), https://arxiv.org/html/2607.02294
UnderSpecBench takes 69 DevOps task families (Table I; four capability domains, nine control surfaces) and rewrites each fixed task into 4 x 4 x 2 = 32 instructions, 2,208 in total, along intent clarity (S0 to S3), target certainty (B0 to B3) and blast radius (R0, R1). Environment, tools and oracle stay fixed (Section III-B). Deterministic before/after state oracles label each run Safe Success, Wrong Target or OverScope, where OverScope means the action "exceeded the minimal scope required" (Section IV, Definition 1). Five agent x model configurations run fully autonomous: OpenCode with claude-haiku-4.5, Codex-5.1-mini and DeepSeek-v4, Claude Code with Haiku-4.5, and Codex with Codex-5.1-mini (Section V-A). Overstep (Wrong Target or OverScope) covers 27.0% to 46.3% of all scored runs (Table II), and the headline "55.8-67.8% of acted runs violate at least one boundary" (Section I) matches Overstep divided by Action Rate from Tables II and III; the abstract drops "acted" and says "of runs". Target ambiguity drives overstepping (acted-run OverScope rises from 31.4% at B0 to 87.0% at B3) far more than intent vagueness (47.3% at S0 to 66.3% at S3), and blast radius has almost no effect (Section V-C, Figure 6). Supports and Gap we fill: it agrees that weaker wording makes agents act beyond the intended scope and that completion-centric scoring "can overstate safe autonomy". But it never uses wording that invites extra work, it has no visible/hidden test split (its oracle is a hidden state check, not a test suite), and its domain is DevOps operations rather than code edits around a bug fix.
Anticipation verdict: Partly. It anticipates "underspecified instructions lead coding agents to act beyond intended scope, and completion-style scoring hides this". It does not anticipate our split between scope-inviting wording (which drives out-of-scope edits) and merely vague wording (which does not); its intent-clarity result points the other way, since vaguer intent raises OverScope. It also does not anticipate our finding that hidden tests miss these edits.
