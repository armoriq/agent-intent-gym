Scaffold a contract, tool schemas, simulated effects, and outcome checks.

uv run intentbench new my-evaluation
uv run intentbench validate my-evaluation/scenario.yaml
uv run intentbench run --suite my-evaluation/scenario.yaml

Native ArmorIQ SDK

The SDK captures submitted plans and checks proposed actions. The gym executes the simulated tools.

uv sync --extra armoriq
export ARMORIQ_API_KEY=...
export ARMORIQ_USER_EMAIL=...
uv run intentbench tui --config examples/armoriq.yaml

Use sdk or local checking modes. Configure backend policy in ArmorIQ; local policy overrides apply to the reference baseline.

Compare policies & run regressions

Measure security alongside useful completion and excessive blocking.

uv run intentbench matrix --agent gullible
uv run intentbench replay RUN_ID --guard reference
uv run intentbench compare BASELINE GUARDED
uv run intentbench gate RUN_ID

Fixed-trace replay measures guard decisions only. Live runs measure the behavior that follows intervention. The bundled scenarios are synthetic micro-tests.
